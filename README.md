# SFTG AI — Официальный B2B-сайт (Беларусь)

> Высококонверсионный технологичный лендинг B2B AI-направления **SFTG AI** (ООО «РоялСиАрЭм», Минск).  
> **Продакшн (Live):** 👉 **[https://sftg-ai.github.io](https://sftg-ai.github.io)**  
> **Целевой национальный домен:** `sftg.by`  
> **Репозиторий:** `sftg-ai/sftg-ai.github.io`

---

## 1. Стек технологий

- **Фронтенд:** React 18 + Vite 5 + Tailwind CSS
- **Иконки:** Lucide React (строгий линейный набор, отказ от эмодзи)
- **Шрифт:** Manrope
- **CI/CD:** GitHub Actions (автоматический билд и публикация на GitHub Pages при пуше в `main`)

---

## 2. Быстрый старт для разработчиков

```bash
# Клонирование репозитория
git clone git@github.com-sftg:sftg-ai/sftg-ai.github.io.git sftg-site
cd sftg-site

# Установка зависимостей
npm install

# Запуск локального сервера разработки (порт 5173)
npm run dev

# Проверка сборки для продакшна
npm run build
```

```

├── sftg-site/                  # Публичный сайт и фронтенд (текущий репозиторий)

```

## 5. Регламент разработки для людей и ИИ-агентов

Все доработки и новые фичи ведутся строго в соответствии с документом [`AGENTS.md`](./AGENTS.md):
- **Сначала согласование:** диалог и утверждение спецификации до написания кода.
- **Жизненный цикл задачи:** каждая задача оформляется в `docs/tasks/<XXX_название>/` (`REQUIREMENTS.md`, `SPECIFICATION.md`, `IMPLEMENTATION_PLAN.md`).
- **Clock-Check верификация:** обязательный успешный прогон `npm run build` перед закрытием задачи и пушем в репозиторий.
- **Дизайн-стандарт:** соблюдение требований скилла `unslop` (отсутствие эмодзи, курсива, хайповых клише, только реальные бизнес-метрики).
