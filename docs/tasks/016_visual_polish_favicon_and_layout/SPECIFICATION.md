## 3. Замедление каскадной анимации процесса (`src/components/ProcessExplorer.jsx`)

Чтобы при клике на любую из 7 кнопок процессов было отчетливо видно, как система шаг за шагом разбирает документ:
- Увеличить длительность CSS-анимации `.animate-process-row` с `320ms` до **`550ms`**:
  ```css
  @keyframes processDocCascade {
    from {
      opacity: 0;
      transform: translateY(10px);
    }
    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
  .animate-process-row {
    opacity: 0;
    animation: processDocCascade 550ms cubic-bezier(0.16, 1, 0.3, 1) forwards;
  }
  ```
- Увеличить шаг задержки (`animationDelay`) между элементами с `90ms` до **`250ms`**:
  - Шапка карточки: `0ms`
  - 1-я строка параметров (`rIdx = 0`): `250ms`
  - 2-я строка параметров (`rIdx = 1`): `500ms`
  - 3-я строка параметров (`rIdx = 2`): `750ms`
  - 4-я строка параметров (`rIdx = 3`): `1000ms`
  - Темная плашка-сигнал отклонения: **`1300ms`**
  - Светло-голубая итоговая плашка записи в Битрикс24 и 1С: **`1600ms`**
