## 1. Проблема рынка и концепция платформы

Большинство агентств каждый раз пишут ботов заново: придумывают стейты, парсят Excel, настраивают интеграцию с CRM — это долго (3–4 недели), дорого и не масштабируется.

**Решение: Собственный модульный движок (AI-Commerce Engine)**
Мы создаём платформу, которая за **5 минут** разворачивает готовое B2B-решение для любого заказчика:
1. Загрузка Excel / 1C / CSV номенклатуры (каталог, артикулы, цены, характеристики).
2. Автоматическая индексация (эмбеддинги + семантический поиск).
3. Мгновенная сборка логики:
   - Приём заказов голосом и текстом.
   - Умный поиск товаров и аналогов.
   - Оформление сделки и связка с Битрикс24 / 1С.

## 2. Киллер-фича на нашем сайте: «Собери своего бота за 60 секунд прямо в браузере»

Вместо скучной формы «Оставьте заявку на созвон» мы ставим на сайт **интерактивную витрину-генератор**:

### Сценарий посетителя сайта (Потенциального клиента):
1. **Шаг 1: Загрузка каталога**
   - Клиент перетаскивает свой прайс-лист (Excel / CSV / PDF) в дропзону на сайте.
   - *(Или выбирает готовый пресет: «Салаты и овощи», «Светодиодное освещение», «Автозапчасти», «Стройматериалы»)*.
2. **Шаг 2: Ввод токена бота**
   - Посетитель вставляет BotFather-токен своего тестового бота в Telegram.
   - *(Или жмёт кнопку «Протестировать во временном демо-боте SFTG»)*.
3. **Шаг 3: Магия за 10 секунд**
   - Бэкэнд парсит прайс, индексирует через Gemini Flash (нативное понимание аудио и контекста с минимальной задержкой).
   - Сайт выдаёт QR-код и ссылку: `t.me/YourCompany_DemoBot`.
4. **Шаг 4: Тест в Telegram**
   - Клиент открывает Telegram, зажимает микрофон и наговаривает:  
     *«Мне три упаковки айсберга и пять метров тёплой ленты»*.
   - Бот мгновенно распознаёт голос, находит позиции в загруженном каталоге и собирает карточку заказа с ценами!
5. **Конверсия 100%:**
   - Клиент в шоке, видит, что это работает на **его реальных товарах**.
   - В конце демо-сессии бот пишет: *«Хотите подключить сюда выгрузку в вашу 1С / Битрикс24 и печать наклеек для склада? Нажмите [Обсудить интеграцию с архитектором]»*.

## 3. Технологический стек фабрики

- **LLM & Vision / Audio:** Google Gemini 2.0 Flash (единая мультимодальная модель: напрямую слушает голосовые сообщения в формате `.ogg/opus` из Telegram без отдельного Whisper, работает за 500–800мс, стоит доли цента).
- **Бэкенд:** Python FastAPI + Redis (быстрый кэш сессий) + PostgreSQL / SQLite (хранилище каталогов).
- **Поиск по каталогу:** Гибридный поиск (BM25 по точным артикулам + Векторный RAG по семантическим описаниям).
- **Коннекторы:**
  - Модуль Telegram Bot API (aiogram).
  - Модуль Битрикс24 REST API (лиды, сделки, товары).
  - Модуль 1C:Предприятие (OData 4.0 / вебхуки).
  - Модуль складских стикеров (генерация PDF с QR-кодом для термопринтера).

## 4. Бизнес-модель и выгода для SoftGreat

1. **Мгновенный пресейл (Zero-Cost Presale):**  
   Сейлзы на созвоне не продают «воздух», а за 3 минуты показывают живого бота на каталоге клиента.
2. **Снижение себестоимости разработки на 70%:**  
   Юлиан не пишет код с нуля — он разворачивает готовое ядро из шаблона, дописывая только специфические интеграции под конкретную 1С клиента.
3. **Рекуррентная выручка (SaaS MRR):**  
   Клиенты платят ежемесячную абонентскую плату ($35 – $100 / мес) за работу движка на нашем сервере.
